Fitbit Calendar Sync – Privacy Policy

Last updated: 18 November 2026

Fitbit Calendar Sync is a personal Google Apps Script. It runs only inside the owner's own Google account and is not offered to the public.

Data accessed

  • Google Health API (read-only): sleep sessions (times, duration, sleep stages) and exercise sessions (type, time, duration, distance, calories, steps, heart-rate summary).
  • Google Calendar: creates and updates events on a calendar named "Fitbit" in the same account.

How data is used

The data is used only to create private, "free" calendar events that summarise each sleep session and workout. Nothing else is done with it.

Storage and sharing

  • No data is stored outside the user's own Google account. The only copies are the calendar events and Apps Script's own execution logs.
  • No data is sold, shared with third parties, or used for advertising, profiling or training models.
  • Use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions, and delete the "Fitbit" calendar to remove all synced events.

Contact

Questions: contact the owner through the support email shown on the Google consent screen.
